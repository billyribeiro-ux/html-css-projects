How does interpolate-size: allow-keywords solve the 25-year height: auto challenge?

Historically, animating to height: auto required measuring scrollHeight with JavaScript or using brittle max-height workarounds. The 2026 standard interpolate-size: allow-keywords instructs the CSS layout engine to compute intrinsic sizing keywords dynamically during transitions.

What is the advantage of native HTML5 name attribute on <details>?

By specifying matching name attributes across multiple <details> elements, the browser natively enforces mutually exclusive accordion behavior. When one is toggled open, all siblings in the same group immediately collapse with built-in accessibility state management.
